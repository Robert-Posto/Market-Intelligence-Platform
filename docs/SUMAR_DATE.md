## 1. Ce colectăm în prezent

| Categorie | Ce conține |
|---|---|
| **Comisioane** (2.1) | Cont curent și pachete, carduri, transferuri, retrageri de numerar — PF și PJ, pe variante de card, doar versiunea în vigoare |

| **Depozite** (2.1) | Dobânzi pe termene și monede |

| **Curs valutar propriu** (2.2) | Cursul afișat de bancă |
| **Indici de referință BNR** (2.2) | ROBOR și ROBID zilnic (7 scadențe), IRCC trimestrial |
| **Aplicații mobile iOS** (2.3) | Versiune, rating, număr de note, distribuția pe stele, capturi din store |
| **Rețea** (2.5) | Sucursale și ATM-uri pe hartă, cu adresă; ATM-uri partenere marcate separat |
| **Recenzii App Store** (2.7) | Recenzii publice, cu nota și răspunsul băncii; autor pseudonimizat |
| **Istoric de prețuri** | Schimbările de comisioane între versiunile documentelor |

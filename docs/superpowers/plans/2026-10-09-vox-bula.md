# Vox: bula din dreapta jos — planul de implementare

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Intrarea în Vox devine o bulă plutitoare în dreapta jos, aceeași pe toate paginile din cadrul aplicației, în locul butonului din bara laterală. Bula nu încurcă nicio pagină.

**Architecture:**
- **Componenta `BulaVox`** (`web/src/layout/BulaVox.tsx`) e un `FloatButton` din Ant Design, cu sigla `VoxBula`, un link spre `#/vox` și textul la hover / focus. E pusă o singură dată în `AppShell` și nu apare pe ruta `/vox`.
- **CSS-ul din `global.css`:**
  - mută bula la stânga barei de derulare a lui `main`;
  - o coboară sub sertarele AntD;
  - mărește spațiul de jos al lui `main`, ca ultimul rând al paginii să rămână deasupra bulei.
- **Verificarea:** un script Playwright pe toate cele 15 pagini, întâi văzut picând, apoi trecând.

**Tech Stack:** React 18 + Ant Design 5 (instalat 5.29.3: `FloatButton.tooltip` acceptă `TooltipProps`), react-router (HashRouter), Playwright (Edge).

```tsx
import { FloatButton } from 'antd'
import { useLocation } from 'react-router-dom'
import { useLang } from '../i18n'
import { VOX } from '../pagini'
import { VoxBula } from '../components/LogoVox'

/**
 * Intrarea în Vox de pe orice pagină (decizia lui Nicolae, 09.10.2026): o bulă în dreapta jos, ca widgetul de chat de
 * pe reginamaria.ro, în locul butonului din bara laterală. Doar duce pe `#/vox`; acolo nu apare, ar trimite pe pagina
 * pe care ești deja. Textul se vede doar la hover sau la focus: mereu vizibil, ar acoperi mai mult din pagini.
 */
export default function BulaVox() {
  const { t } = useLang()
  const { pathname } = useLocation()
  if (pathname === `/${VOX.id}`) return null
  const text = t('vox.nav.buton')
  return (
    <FloatButton
      className="vox-lansator"
      type="primary"
      shape="circle"
      href={`#/${VOX.id}`}
      icon={<VoxBula size={20} />}
      aria-label={text}
      tooltip={{ title: text, placement: 'left', trigger: ['hover', 'focus'] }}
    />
  )
}
```
